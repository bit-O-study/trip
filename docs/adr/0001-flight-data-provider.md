# ADR-0001: 항공 데이터 공급자 선정

- 상태: **제안 (검증 미완료)**
- 작성일: 2026-08-19
- 결정 기한: 구현 순서 7단계(항공 provider adapter) 착수 전

---

## 배경

편명과 출발일로 실제 운항편을 조회해 일정에 저장해야 한다. 공급자는 `src/features/flights/provider.ts`의 공통 `FlightSearchResult` 타입 뒤에 adapter로 격리하므로, **공급자 선정이 늦어져도 다른 단계의 구현을 막지 않는다.**

## 후보

### A. 공공데이터포털 — 한국공항공사_실시간 항공기 운항정보 조회_GW

기존 `한국공항공사_항공기 운항정보` API는 **2026년 6월 12일 공지로 폐기**됐고 위 GW API로 전환됐다. 기존 서비스 URL은 **공지 후 90일만 유지**된다(2026년 9월 중 중단). 따라서 인터넷의 기존 예제·블로그는 대부분 폐기된 엔드포인트를 가리키므로 신뢰하지 않는다.

- 비용: 무료
- 활용 신청 승인에 1~2일 소요

### B. AeroDataBox

- 전 세계 편명 커버리지
- 판매 채널(RapidAPI / API.market / 직접)과 시점에 따라 **가격과 무료 단위가 다르다.** 발급 시점에 가격표를 직접 확인하고 아래 표에 기록한다.

### C. 기타 (AviationStack, FlightAware AeroAPI 등)

A·B가 요구사항을 못 채울 때만 검토한다.

---

## 결정 전 반드시 검증할 항목

후보 A를 "1순위"로 확정하기 전에 **실제 샘플 응답으로** 아래를 확인한다. 하나라도 미충족이면 B를 1순위로 올린다.

|---|---|---|---|
| 1 | 인천공항(ICN) 포함 여부 | 미확인 | |
| 2 | 국제선 편명 검색 가능 여부 | 미확인 | |
| 3 | 코드셰어 편명 검색 가능 여부 | 미확인 | |
| 4 | 미래 운항 스케줄 조회 범위 (며칠 앞까지) | 미확인 | |
| 5 | 출발·도착 터미널 필드 제공 | 미확인 | |
| 6 | 게이트 필드 제공 | 미확인 | |
| 7 | 지연·결항 상태 필드 제공 | 미확인 | |

4번이 특히 중요하다. 여행 계획은 보통 **수 주~수 개월 전**에 세우는데, 실시간 운항정보 API가 당일·익일 데이터만 제공하면 MVP 기준 3번을 충족하지 못한다. 이 경우 스케줄 조회용 공급자를 별도로 두거나 B를 1순위로 올린다.
