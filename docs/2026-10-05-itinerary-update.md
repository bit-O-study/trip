# 2026-10-05 숙박·메모·조회 성능 개선

- 숙박 추가·수정에서 체크인과 체크아웃 날짜/시간을 받고, 일정 및 공유 화면에서 둘 다 표시한다. 체크아웃은 체크인 이후여야 한다. 기존 숙박에 종료 시각이 없으면 미입력으로 표시한다.
- 장소 검색 후 시간 선택 단계와 항공편 검색/수동 추가에 메모 입력을 추가했다. 기존 수동 일정·수정 메모와 함께 모든 일정 추가 경로에서 메모를 저장한다. 최대 2000자이며 항공 메모는 공유 flights 행이 아닌 해당 itinerary_items 행에 저장한다.
- 날짜 포맷터를 시간대별로 최대 32개 재사용한다. 사용자 데이터나 인증 결과를 전역 캐시하지 않는다.
- 투표가 없으면 마감 RPC·후보·인증 조회를 생략한다. 마감된 열린 투표가 있을 때만 마감 처리 후 다시 읽는다.

기존 컬럼을 사용하므로 DB 마이그레이션 없이 배포할 수 있다. 구간별 이동정보 저장은 별도 마이그레이션과 후속 브랜치에서 제공한다.
